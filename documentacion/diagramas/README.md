# Diagramas

Los diagramas técnicos y UML se mantienen como código fuente PlantUML dentro de `plantuml`. Las imágenes exportadas se generan a partir de esas fuentes y no deben sustituirlas.

Cada diagrama debe ser comprensible por sí mismo, corresponder con la implementación vigente y conservar la numeración utilizada en el documento académico cuando aplique.
