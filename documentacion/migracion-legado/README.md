# Migración del código anterior

Esta carpeta registra el análisis del desarrollo anterior y la decisión tomada para cada elemento: reutilizar, adaptar, reescribir o descartar.

El código legado no se copiará directamente al nuevo proyecto. Toda incorporación debe justificar su utilidad, eliminar secretos o datos reales, ajustarse a la arquitectura vigente e incluir las pruebas correspondientes.
