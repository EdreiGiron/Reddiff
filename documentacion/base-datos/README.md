# Documentación de la base de datos

Aquí se documentarán el modelo relacional de PostgreSQL, las convenciones de nombres, las relaciones, restricciones, índices y decisiones de persistencia.

Las migraciones ejecutables pertenecen al proyecto `RedDiff.Infraestructura`; esta carpeta explica el modelo y conserva diagramas o decisiones, pero no duplica el código de las migraciones.
