# Documentación del proyecto

Esta carpeta conserva la documentación técnica que debe evolucionar junto con el código.

| Carpeta | Contenido |
| --- | --- |
| `api` | Contrato HTTP, versionado y ejemplos seguros de consumo. |
| `arquitectura` | Estructura, componentes, dependencias y modelos técnicos. |
| `base-datos` | Modelo relacional, convenciones y decisiones de persistencia. |
| `decisiones` | Decisiones de arquitectura y sus consecuencias. |
| `despliegue` | Estrategia por entorno, publicación y reversión. |
| `diagramas` | Fuentes PlantUML y representaciones derivadas. |
| `migracion-legado` | Inventario y tratamiento controlado del código anterior. |
| `requisitos` | Requisitos funcionales, no funcionales y trazabilidad. |
| `seguridad` | Modelo de amenazas, controles y revisiones. |
| `pruebas` | Estrategia, escenarios y evidencias de calidad. |
| `operacion` | Desarrollo local, despliegue, respaldo y recuperación. |

Los documentos académicos finales se mantendrán separados del código cuando incluyan datos, formatos o anexos que no formen parte de la documentación técnica operativa.
